# Aseprite MCP Live Mode

This fork keeps all 104 tools from `diivi/aseprite-mcp` and adds a WebSocket Live Bridge derived from `ZhangDongyang800/Aseprite_MCP`.

## What Live Mode changes

- The MCP server still exposes the same tool set.
- Lua generated by those tools is executed inside the already-running Aseprite UI.
- The active sprite stays visible and persistent across tool calls.
- You can watch AI-driven edits happen in Aseprite.
- If the live bridge is unavailable, the server falls back to the original CLI/batch execution by default.

## 1. Install dependencies

```bash
pip install -r requirements.txt
```

Aseprite 1.3+ is required.

## 2. Install the Aseprite extension

Install the repository's `extension/` directory as an Aseprite extension, or copy its files into your Aseprite scripts/extensions folder.

Then launch Aseprite and run:

`MCP Live Bridge: Toggle Connection`

The status command is:

`MCP Live Bridge: Show Status`

## 3. Start the MCP server in live mode

Set these environment variables in your MCP client configuration:

```text
ASEPRITE_MCP_MODE=ws
ASEPRITE_WS_HOST=127.0.0.1
ASEPRITE_WS_PORT=9001
ASEPRITE_WS_TIMEOUT=30
ASEPRITE_MCP_WS_FALLBACK=1
```

`ASEPRITE_MCP_WS_FALLBACK=1` keeps the original CLI behavior available when Aseprite is not connected. Set it to `0` if you want live-mode connection failures to fail immediately instead.

## Codex CLI example

```toml
[mcp_servers.aseprite]
command = "uv"
args = ["run", "-m", "aseprite_mcp"]

[mcp_servers.aseprite.env]
ASEPRITE_MCP_MODE = "ws"
ASEPRITE_WS_HOST = "127.0.0.1"
ASEPRITE_WS_PORT = "9001"
ASEPRITE_WS_TIMEOUT = "30"
ASEPRITE_MCP_WS_FALLBACK = "1"
ASEPRITE_PATH = "C:\\Program Files\\Aseprite\\aseprite.exe"
```

## Claude Desktop / other stdio MCP clients

Use the same environment variables with your normal `python -m aseprite_mcp` or `uv run -m aseprite_mcp` stdio configuration.

## Execution flow

```text
AI / MCP client
      |
      | stdio MCP
      v
aseprite-mcp (104 tools)
      |
      | generated Lua script
      v
Python WebSocket bridge :9001
      |
      v
Aseprite Live Bridge extension
      |
      v
running Aseprite UI / active sprite
```
